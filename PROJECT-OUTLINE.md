# Tabula — Project Outline

## Purpose
Create an interactive Latin-learning website based on Jenney's First Year Latin. The goal is to help students learn, practice, and master Latin.

## Main Categories
1. Nouns
2. Verbs
3. Grammar

## Lessons and Practice
- Include short lessons explaining each topic.
- Provide interactive exercises.
- Organize exercises by chapter.
- Allow students to review previously learned material.
- Build on concepts as students progress.

## Progress Tracking
- Track student progress.
- Show which topics have been mastered.
- Identify topics that need more practice.
- Aim for approximately 95–100% mastery.

## Website Design
- Keep the layout clean and organized.
- Use clearly labeled sections.
- Include collapsible sections.
- Make navigation simple.
- Arrange lessons and exercises in a logical progression.

## Overall Goal
Create a Latin study tool that lets students learn at their own pace, practice regularly, and track their understanding.
